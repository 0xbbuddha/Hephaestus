# Hephaestus

Mythic C2 wrapper for the **Aphrodite** agent. Hephaestus is a Windows loader written in Nim that receives Aphrodite shellcode (generated via donut), encrypts it, and injects it into a target process.

---

## Prerequisites

1. **Aphrodite** must be installed in Mythic.
2. Building a Hephaestus payload requires an **Aphrodite payload in shellcode format** first:
   - `target_os` = `windows`
   - `output_format` = `shellcode`
   - Disable **Encrypted Key Exchange** in the C2 profile (PSK only)

---

## Usage in Mythic

### Step 1 — Build the Aphrodite shellcode

```
Payloads → Generate New Payload
  Agent         : aphrodite
  OS            : Windows
  output_format : shellcode
  C2 Profile    : http (or websocket)
  ⚠ Uncheck "Encrypted Key Exchange"
```

### Step 2 — Build the Hephaestus wrapper

```
Payloads → Generate New Payload
  Agent : hephaestus
  → Select the Aphrodite payload created in Step 1
  → Configure the build parameters below
```

---

## Build Parameters

| Parameter | Values | Default | Description |
|---|---|---|---|
| `encryption_type` | `rc4` / `xor` / `none` | `rc4` | Encryption applied to the embedded shellcode |
| `encryption_key` | string | *(random 16 bytes)* | Encryption key (leave empty for a random key) |
| `target_process` | absolute path | `C:\Windows\System32\notepad.exe` | Process spawned suspended for injection |
| `injection_technique` | `earlybird` / `threadhijack` | `earlybird` | Shellcode injection technique |
| `ppid_spoof` | bool | `true` | Spoof parent PID to appear as a child of explorer.exe |
| `use_unhook` | bool | `true` | Remap ntdll `.text` section from a clean on-disk copy to remove EDR userland hooks |
| `use_etw_patch` | bool | `true` | Patch `EtwEventWrite` (`xor eax,eax; ret`) |
| `use_amsi_patch` | bool | `false` | Patch `AmsiScanBuffer` |
| `use_sandbox_check` | bool | `true` | Basic sandbox detection (uptime, RAM, CPU count, sleep skipping) |
| `wipe_memory` | bool | `true` | Zero out the shellcode buffer in heap after injection |
| `debug_mode` | bool | `false` | Debug build: console window + verbose output (do NOT use in production) |

---

## Injection Techniques

### `earlybird` (recommended)
Spawns the target process suspended → `VirtualAllocEx` + `WriteProcessMemory` → `NtQueueApcThread` on the main thread → `ResumeThread`. Shellcode executes before the process entry point is ever reached.

### `threadhijack`
Spawns suspended → allocates and writes shellcode → `GetThreadContext` → redirects RIP to shellcode → `SetThreadContext` → `ResumeThread`.

---

## Execution Flow

```
Hephaestus.exe
 ├── [sandbox_check]      uptime > 10min, RAM > 2GB, CPU > 1 core, sleep skipping
 ├── [use_unhook]         re-read ntdll.dll from disk, overwrite .text section in memory
 ├── [use_etw_patch]      VirtualProtect + patch EtwEventWrite
 ├── [use_amsi_patch]     VirtualProtect + patch AmsiScanBuffer
 ├── decrypt shellcode    RC4 / XOR / none (key compiled into the binary)
 ├── spawn target_process CREATE_SUSPENDED [+ PPID spoof if enabled]
 ├── VirtualAllocEx(RW) + WriteProcessMemory
 ├── VirtualProtectEx(RX)
 ├── inject               earlybird (APC) or threadhijack (RIP redirect)
 ├── ResumeThread
 └── [wipe_memory]        memset shellcode buffer → 0
```

---

## OPSEC Notes

- Build Aphrodite with `obfuscation=xor` or `obfuscation=aes` before wrapping with Hephaestus.
- `ppid_spoof` hides the parent/child relationship from EDRs that monitor the process tree.
- `use_unhook` is effective against EDRs that hook ntdll in userland (CrowdStrike, SentinelOne, etc.).
- `debug_mode=false` hides the console window and strips the binary — only enable for development.
- The shellcode is encrypted **inside the binary** with a key generated at build time. Every build produces a unique binary.

---

## Tech Stack

- **Language**: Nim (cross-compiled for Windows from Linux via mingw-w64)
- **Shellcode**: generated by [donut](https://github.com/TheWover/donut) from the Aphrodite PE
- **WinAPI**: winim (Nim bindings)
- **Encryption**: RC4 (16 bytes) or XOR (16 bytes), implemented natively in Nim
